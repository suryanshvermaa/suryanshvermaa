  - Integrates AWS S3
  - **Stack:** Node.js, MongoDB, Docker, AWS S3, NPM

  - Wires AWS S3 client and generates a Dockerfile
  - **Stack:** C++17, Drogon, CMake, Docker, PostgreSQL

  - CI/CD pipeline with Jenkins for automated builds, tests, and deployments
  - **Stack:** C++17, Drogon, Jenkins, Kubernetes, PostgreSQL
